## How to run

Requires `pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`.

### Windows PowerShell setup

From the project root, create and activate a virtual environment, then
install the required packages:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pandas numpy scipy matplotlib seaborn
```

After activation, run the pipeline from the `scripts` directory:

Step 6 both displays the chart in an interactive window (`plt.show()`)
and saves it to `results/figures/possession_diff_plot.png` — so you'll
see it pop up when you run the script, and it's still on disk afterwards.

```powershell
cd scripts
python .\run_all.py
```

If the virtual environment is not activated, run the pipeline with its
interpreter explicitly from the project root:

```powershell
cd scripts
..\.venv\Scripts\python.exe .\run_all.py
```

This regenerates everything in `data/processed/` and `results/` from the
raw CSV. You can also run the six numbered scripts one at a time, in
order — each one only depends on files produced by the previous step:

```powershell
cd scripts
python .\Questions2\01_data_wrangling.py
python .\Questions2\02_data_preparation_sampling.py
python .\Questions2\03_descriptive_statistics.py
python .\Questions2\04_confidence_interval.py
python .\Questions2\05_hypothesis_testing.py

```

## Data provenance

`data/raw/team_match_possession_raw.csv` was hand-compiled from official
match-centre statistics (Sky Sports/Opta, TNT Sports/Eurosport) and
cross-checked against post-match wire reporting, for 15 FIFA World Cup
2026 matches spanning the group stage through the Final (group stage,
every Round of 32/16, every quarter-final, both semi-finals, the
3rd-place play-off, and the Final). See `results/sampling_summary.txt`
(generated by step 2) for the population definition, sample size, and
sampling technique used — and why this is 15 matches rather than all 104:
match-level possession is not published centrally for every game, so each
row had to be individually verified against a named source (see the
`source` column in the raw CSV). More rows can be appended to the raw CSV
at any time; the pipeline re-wrangles and re-analyses automatically.

## Headline result

The one-sample t-test on the paired possession differences (the correct
test, since a match's two possession figures always sum to 100% and are
therefore not independent) does **not** reach significance at α = 0.05 for
this sample (see `results/hypothesis_test_results.txt`). The same script
also reports what an (incorrect) independent two-sample t-test would have
concluded, to show numerically why ignoring the pairing inflates
significance.
